# 스탭 허브 v0.1

배우·관객·스탭 3자 정서 피드백 루프의 노트북 프로그램. 브라우저 화면에서 배우·관객 각성 그래프, 승인/거부/차단, 큐, 대본을 본다.

## 바로 해보기 (장비 없이)
    python3 hub.py --demo --speed 4 --autoplay --script sample_script.md
브라우저에서 http://localhost:8000 . 데모는 가짜 신호·가짜 장치이며 프로토콜 부록 B의 곡선을 쓴다.

## 실제 장비
    pip3 install pyserial
    python3 hub.py --list-ports
    python3 hub.py --seat serial:COM5 --actor udp:5006 --script 내대본.md
- 좌석 보드(시리얼 115200, 한 줄씩): `S,ms,front,back,gsr,hr,hr_ok` / `R,ms,rr` / `M` / `A,id,pattern`(명령 확인). 허브는 `V,id,pattern`(weak|strong)과 `X`(전부 끄기)를 보낸다.
- 배우 보드(UDP): `H,ms,hr,ok` / `R,ms,rr` / `ack,id,pattern` 을 허브 5006 포트로 보내고, 허브는 `id,pattern` / `off` 를 보드 4210 포트로 보낸다.
- 배우 보드가 와이파이와 블루투스를 같이 못 쓰면: `--actor ble:Polar --actor-ip 보드IP` (bleak 필요, 실험적).

## 규칙 (pilot-protocol-v3)
- 점수: 개인 기준선 z → 0~1, 낮음<0.45≤중간<0.70≤높음, 히스테리시스 0.03. 관객은 심박·GSR·좌석 가중 평균.
- 배우→관객: 높음 5초 유지 시 승인 요청. 승인해야 좌석 진동. 쿨다운 30초, 45초 뒤 만료.
- 관객→배우: 낮음→중간 약, 중간→높음 강. 내려갈 때는 안 보냄. 기본 2초 안에 차단 가능, 간격 6초·분당 6회 제한.
- 큐: 30초 간격, 최대 5회. 램프 장치는 미정이라 지금은 기록만(`--lamp-ip` 로 UDP 연결 가능).
- 전체 정지(X): 진동 끄기 + 대기 중인 것 모두 취소. 피드백 OFF 버튼은 대조 조건용.
- 단축키: A 승인, R 거부, B 차단, X 전체 정지.

## 대본
`### 비트 1 · 도입 (0:00~1:20) — 메모` 형식이면 공연 시계를 따라 현재 구간이 강조된다. 구간을 누르면 직접 선택. 비트 시트 표가 있으면 구간별 예상 각성이 함께 보인다.

## 기록 (logs/날짜_시각/)
events.csv(이벤트·승인·차단·큐·지연), signals.csv(점수와 원값), raw_*.csv, rr_*.csv, script.md.

## 주의
- 기준선은 2분 이상. 기준선 없이 시작하면 임시 기준을 쓴다.
- GSR 방향이 반대로 나오면 설정에서 GSR 방향을 바꾼다.
- 가중치·경계값은 초기값이라 리허설 데이터로 조정한다.
- 배우 보드의 와이파이+폴라 동시 동작은 아직 검증 전이다.
- `--host 0.0.0.0` 은 같은 네트워크의 누구나 조작할 수 있으니 쓰지 말 것.
